# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful and welcoming; assume good intent; give and accept
constructive feedback; no harassment, insults, or discriminatory jokes or
language; no publishing others' private information. These rules apply in
issues, pull requests, discussions and any other project space.

**Reporting:** if someone's behaviour makes you uncomfortable, contact the
maintainers privately through the repository's security/contact channel
(see [SECURITY.md](SECURITY.md)). Reports are handled confidentially.
Maintainers may remove comments, commits or contributions, or temporarily or
permanently ban anyone whose behaviour breaks this code of conduct.
